LiveArea assets for maytube-vita: original artwork (a play-triangle mark
+ "maytube" wordmark on a flat dark ground, in the same blue the in-app
UI uses for its selection highlight), generated for this project -- not
based on or lifted from any existing brand's assets.

- `icon0.png` (128x128) -- app icon shown in the LiveArea grid.
- `livearea/contents/bg.png` (840x500) -- LiveArea background.
- `livearea/contents/startup.png` (280x158) -- brief boot splash.
- `livearea/contents/template.xml` -- LiveArea layout referencing the above.

Standard PS Vita LiveArea asset sizes and template.xml shape, per
VitaSDK's own `pretty_livearea` sample.
