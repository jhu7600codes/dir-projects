# раритет

русская викторина на редкие ответы. 7 вопросов, 20 секунд на каждый, за правильный ответ дают
100 минус 2 × (сколько процентов игроков ответили бы так же), но не меньше 10. «москва» почти ничего не стоит,
«фонтанка» стоит почти 100.

- игра дня: одни и те же 7 вопросов у всех на дату, переигрывать можно сколько хочешь, засчитывается лучший результат
- бесконечный режим: случайные вопросы, без лимитов
- ответы на русском, латиница тоже работает (`ria news` = риа новости), опечатки в 1-2 буквы прощаются

## файлы
- `web/`: вся игра (один index.html), тот же код в dpk и в apk
- `raritet.dpk`: для droid, просто перетащи файл туда
- `raritet.apk`: для android 5.0+, webview вокруг `web/index.html`
- `android/`: исходники apk (без gradle)

## сборка
```bash
ANDROID_HOME=~/Android/Sdk DROID=../../droid ./build.sh
```
нужны build-tools 34.0.0 и platforms;android-34. без `DROID` собирается только apk.
apk подписан debug ключом из `android/debug.keystore`, его не удаляй, иначе обновление поверх не встанет.

## вопросы
лежат в `BANK` в начале скрипта в `web/index.html`, формат `ответ|синоним|синоним=процент`.
