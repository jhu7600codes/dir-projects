# раритет

русская викторина на редкие ответы. 7 вопросов, 20 секунд на каждый, за правильный ответ дают
100 минус 2 × (сколько процентов игроков ответили бы так же), но не меньше 10. «москва» почти ничего не стоит,
«фонтанка» стоит почти 100.

- режимы: игра дня (7 вопросов, одни на всех, переигрывать можно), бесконечный, блиц (60 секунд), дзен (без таймера), геймер
- два языка: русский (58 вопросов) и english (47 questions), со своими вопросами и ответами
- геймер: 21 вопрос про Roblox (DOORS, Natural Disaster Survival, предметы), Geometry Dash, Minecraft, Terraria, FNAF, Brawl Stars, Nintendo, Valve, на обоих языках
- бросок: ответ улетает из рогатки на столько метров, сколько очков он стоит, а остальные ответы стоят флажками на поле (можно выключить в настройках)
- после ответа видно топ ответов с процентами и где твой
- подсказка (1 за игру, первая буква редкого ответа, половина очков), статистика, график за 14 дней, 12 достижений
- настройки: язык, таймер 15/20/30 с, звук, вибрация
- латиница тоже работает (`ria news` = риа новости), опечатки в 1-2 буквы прощаются

## файлы
- `web/`: вся игра, тот же код в dpk и в apk (`app.js` логика, `i18n.js` тексты, `bank-ru.js` / `bank-en.js` / `bank-gamer.js` вопросы)
- `raritet.dpk`: для droid, просто перетащи файл туда
- `raritet.apk`: для android 5.0+, webview вокруг `web/index.html`
- `android/`: исходники apk (без gradle)

## сборка
```bash
ANDROID_HOME=~/Android/Sdk DROID=../../droid ./build.sh
```
нужны build-tools 34.0.0 и platforms;android-34. без `DROID` собирается только apk.
apk подписан debug ключом из `android/debug.keystore`, его не удаляй, иначе обновление поверх не встанет.

## вопросы
лежат в `web/bank-ru.js`, `web/bank-en.js` и `web/bank-gamer.js` (там вопрос на двух языках), формат `ответ|синоним|синоним=процент`.
