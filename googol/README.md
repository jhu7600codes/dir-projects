# googol

a calculator for googologists. it has buttons for TREE(3), SSCG(3), SCG(13),
graham's number, rayo(10¹⁰⁰), BB(6), loader's number, f_ε₀(10), ∞+1,
googolplex!, absolute infinity and ÷0. it "calculates" every one of them
(progress bar, status lines, digits streaming in) and then says no.

the normal keypad is a working basic calculator. dividing by zero or
overflowing a double gets you a no too.

kotlin + jetpack compose, minSdk 26. apk in `dist/`.
