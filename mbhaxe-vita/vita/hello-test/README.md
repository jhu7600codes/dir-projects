# Vita toolchain smoke test

A trivial Haxe program (`Main.hx`, just a `trace()`) that exercises the
*entire* pipeline this port depends on, with nothing game-specific in the
way: `haxe compile.hxml` (Haxe → HashLink `hlc` C) → `arm-vita-eabi-gcc`
against the ported `../hashlink/src` runtime (see `../hashlink/NOTICE.md`)
→ `vita-elf-create`/`vita-make-fself`/`vita-mksfoex`/`vita-pack-vpk` → a
real, installable `.vpk`.

This has actually been built and packaged successfully (produced a working
`.vpk`, not just "it compiled") against a from-source vitasdk build. It
doesn't render anything — it's a console `trace()` with no display output
hooked up — so on real hardware expect it to install and launch to a blank
screen without crashing. That's the point: it isolates "does the ported
runtime work at all" from "does rendering work," which is the actual open
question (see `../VITA_PORT.md`).

## Reproducing this

You need: a working `vitasdk` install (`$VITASDK` set, `PATH` includes
`$VITASDK/bin`) with a full `arm-vita-eabi-gcc` — specifically one where
`gcc-final-target-libs` was built, not just `gcc-final`/`all-gcc`. If
you're building vitasdk yourself from
[vitasdk/buildscripts](https://github.com/vitasdk/buildscripts) rather than
using a prebuilt release, see "toolchain gotchas" in `../VITA_PORT.md` —
that target-libs step doesn't run by default and its absence fails silently
(you get a compiler with no `libgcc.a`/`crti.o`, not an error, until you try
to link something).

```sh
# 1. Haxe -> HashLink C
haxe compile.hxml
# produces native/hello.c (+ native/hl/*.c helpers, generated by haxe itself)

# 2. Build libhl for arm-vita-eabi (see ../hashlink/)
HL=../hashlink
SRCS="$HL/src/gc.c $HL/src/std/*.c $HL/include/pcre/*.c"
mkdir -p build-libhl && cd build-libhl
for f in $SRCS; do
  arm-vita-eabi-gcc -c -O2 -std=c11 -D_GNU_SOURCE \
    -I$HL/src -I$HL/include -I$HL/include/pcre \
    -DHL_VITA -DHAVE_CONFIG_H -DPCRE2_CODE_UNIT_WIDTH=16 \
    "$f" -o "$(basename "$f" .c).o"
done
arm-vita-eabi-ar rcs libhl.a *.o
cd ..

# 3. Compile + link the generated program against it
cd native
arm-vita-eabi-gcc -c -std=c11 -D_GNU_SOURCE -DHL_VITA -I. -I../$HL/src hello.c -o hello.o
arm-vita-eabi-gcc -Wl,-q hello.o ../build-libhl/libhl.a -lpthread -lm -o hello.elf

# 4. Package as a VPK
vita-elf-create hello.elf hello.velf
vita-make-fself hello.velf eboot.bin
vita-mksfoex -s TITLE_ID="MBHXVITA" "MBHaxe Vita Test" param.sfo
vita-pack-vpk -s param.sfo -b eboot.bin hello.vpk
```

Install `hello.vpk` with VitaShell (or equivalent) same as any other
homebrew `.vpk`.
